# Roundtrip Examples Index

Purpose:

- support the workflow:
  source `.prm` -> reverse prompt -> regenerated `.prm`

Recommended stored artifacts per case:

- source `.prm`
- reverse prompt text
- regenerated `.prm`
- repair output if needed
- validation result
- metrics summary

Good categories for early roundtrip experiments:

- onset of convection
- convection box
- free surface
- prescribed velocity
- shell simple 2d

Reason:

- these span multiple geometries and physics levels without being the noisiest
  possible cases
