# Test Examples Index

Primary source:

- ASPECT repository `tests/`

Purpose:

- retrieve small focused examples that expose valid parameter names, subsection
  structure, and edge-case configuration patterns

Use test examples when:

- a generated file fails on syntax or subsection naming
- you need the smallest valid pattern for a specific feature
- a full cookbook is too large or noisy for retrieval

Caution:

- tests are often incomplete as scientific examples
- they are best used for structure and parameter naming, not as the only source
  for realistic full-model generation
