# Benchmark Examples Index

Primary source:

- ASPECT repository `benchmarks/`

Purpose:

- retrieve cases that are useful for validation, standard formulations, and
  comparisons to known setups

Use benchmark examples when:

- the user asks for a canonical setup
- the task is close to a known benchmark
- you want a minimal but disciplined reference case

Generation note:

- benchmark examples are often cleaner templates than large cookbooks
- prefer them when the requested physics is narrow and well defined
